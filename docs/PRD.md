# Product Requirements Document

## Vision

Build an AI-powered Engineering Intelligence Platform that helps engineering leaders understand delivery health, identify risks, and prioritize work by continuously analyzing engineering signals.

## Goal

Provide engineering leaders with actionable insights from GitHub, Jira and CI/CD using AI.

## Target Users

-   Engineering Managers
-   Tech Leads
-   CTOs
-   Principal Engineers

## MVP Objective

Answer three key questions: 
1. What changed yesterday? 
2. What is currently at risk?
3. What should the team focus on today?

## Core Features

-   Organization & user management
-   GitHub integration (OAuth, webhooks, repository sync)
-   Jira integration (boards, sprints, issues)
-   Engineering dashboard
-   AI daily engineering summary
-   AI PR insights (summary, risk, complexity)
-   Sprint health & delivery risk
-   Natural language search across engineering data

## User Stories

-   As a manager, I want to see engineering health in one dashboard.
-   As a lead, I want to identify risky PRs before release.
-   As an executive, I want a daily AI summary.
-   As a developer, I want AI-generated PR summaries.

## Success Metrics

-   < 10 min onboarding
-   Daily active managers
-   Weekly AI summary engagement
-   Time saved in release planning
